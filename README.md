## 📌 Overview

QuizVortex is an advanced web-based quiz application that enables users to test their knowledge across multiple domains including music, sports, anime, books, films, and more. The platform integrates gamification features such as streak combos, leaderboards, timed quizzes, and difficulty levels to deliver an engaging and interactive user experience.

---

## ✨ Key Features

### 🎯 Quiz Functionality

* Multiple quiz categories
* Randomized questions and answer options
* Timed question system
* Skip question functionality
* Answer review after quiz completion

### 🏆 Gamification Features

* Real-time score tracking
* Streak combo system
* Performance-based feedback
* Local leaderboard using browser storage
* Confetti animation for high scores

### 🎨 User Experience

* Modern glassmorphism-inspired UI
* Dark and Light theme support
* Fully responsive design
* Smooth animations and transitions
* Keyboard accessibility support

### ⚙️ Difficulty Levels

* **Easy** – 20 seconds per question
* **Medium** – 15 seconds per question
* **Hard** – 10 seconds per question with penalties

## 🚀 Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Kanishk-1009/QuizVortex.git
```

Navigate to the project directory:

```bash
cd QuizVortex
```

Run the application by opening:

```text
index.html
```

in your browser.

No additional dependencies or installations are required.

---

## 🎮 How to Use

1. Launch the application.
2. Select a difficulty level.
3. Choose a quiz category.
4. Answer questions before the timer expires.
5. Save your score to the leaderboard.
6. Review your answers and improve your performance.
